# Chapters / Blossoms

The English edition is organized into **100 numbered “Blossom” sections**.

The complete source-derived title list and printed starting pages are preserved in [`../contents/index.md`](../contents/index.md). Each completed Blossom has a dedicated chapter record linking its page-level transcription files.

## Working page map

The numbered text begins with **Blossom 1** on scan page **31**, printed page **1**. The working relation is therefore:

`scan page = printed page + 30`

This relation is used only to plan batches. Every boundary must be confirmed visually against the source scan before a blossom is marked complete.
