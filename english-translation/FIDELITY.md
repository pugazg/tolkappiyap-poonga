# Text Fidelity Audit

This tracker records a second-pass, source-faithful comparison of the English transcription against the scanned edition. The scan remains authoritative: printed wording, punctuation, capitalization, transliteration, diacritics, verse lineation and apparent source irregularities are preserved rather than silently normalized.

## Method

- Audit the 100 numbered Blossoms in **20-Blossom iterations**.
- Compare every page in each iteration directly with the source scan.
- Use OCR only as a navigation aid; it is not accepted as source authority.
- Correct only discrepancies between the Markdown transcription and the printed scan.
- Preserve source mistakes, inconsistencies and unusual punctuation when the scan confirms them.
