# Blossom 13 — Commercial Competency · continued

> If one has to say  
> ‘It is but unavailable’  
> When a certain commodity is asked for,  
> One must do so  
> By pointing to something else that is available.
>
> (*Collatikāram : Kiḷaviyākkam*, verse 35)
