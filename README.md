# தொல்காப்பியப் பூங்கா — பக்கவாரி மின்னாக்கம்

கலைஞர் மு. கருணாநிதி எழுதிய **தொல்காப்பியப் பூங்கா** நூலின் 537-பக்க ஸ்கேன் பிரதியைப் பக்கம்தோறும் வாசித்து, Markdown வடிவில் பாதுகாக்கும் களஞ்சியம்.

## நோக்கம்

- மூல ஸ்கேனின் பக்க வரிசையை மாற்றாமல் பாதுகாத்தல்
- அட்டை, பதிப்புத் தகவல், பதிப்புரை, உள்ளடக்கம் போன்ற முன்பக்கங்களை தனித்தனியாகப் பதிவு செய்தல்
- நூலில் உள்ள 100 “மலர்” தலைப்புகள், அதிகாரம், இயல், நூற்பா எண்கள் மற்றும் புத்தகப் பக்க எண்களை உள்ளடக்க அட்டவணைப்படி பாதுகாத்தல்
- ஒவ்வொரு ஸ்கேன் பக்கத்துக்கும் தனி Markdown கோப்பு உருவாக்குதல்
- படிக்க முடியாத அல்லது உறுதியாகத் தெரியாத எழுத்துகளை ஊகித்து நிரப்பாமல் வெளிப்படையாகக் குறித்தல்

## மூலப் பிரதியின் அளவு

- PDF பக்கங்கள்: **537**
- முதல் பதிப்பு: **சனவரி 2003**
- வெளியீடு: **தமிழ்க்கனி பதிப்பகம், சென்னை - 600 004**

## களஞ்சிய அமைப்பு

```text
metadata/                 நூல் மற்றும் மின்னாக்கத் தகவல்கள்
indexes/                  உள்ளடக்கம், மலர் அட்டவணை, பக்க வரைபடம்
pages/                    ஒவ்வொரு ஸ்கேன் பக்கத்திற்கும் தனி Markdown
chapters/                 அணிந்துரை மற்றும் 100 மலர்களின் அத்தியாய அமைப்பு
```

## மின்னாக்க நிலைகள்

- `verified` — ஸ்கேனுடன் நேரடியாக ஒப்பிட்டு உறுதிப்படுத்தப்பட்டது
- `partial` — ஒரு பகுதி மட்டும் தெளிவாக வாசிக்கப்பட்டது
- `needs-review` — மறுபார்வை தேவை
- `not-started` — இன்னும் வாசிக்கப்படவில்லை

## தற்போதைய முன்னேற்றம்

முதல் தொகுதியாக ஸ்கேன் பக்கங்கள் **1–9** பதிவு செய்யப்படுகின்றன. இவை அட்டை, தலைப்புப் பக்கம், பதிப்புத் தகவல், கையெழுத்துப் பதிவு, பதிப்புரை மற்றும் 100 மலர்களுக்கான நான்கு பக்க உள்ளடக்க அட்டவணையை உள்ளடக்குகின்றன.

> குறிப்பு: இது தானியங்கி OCR வெளியீடு அல்ல. ஒவ்வொரு பக்கமும் ஸ்கேனைப் பார்த்து பதிவு செய்யப்படும்; சந்தேகமான வாசிப்புகள் வெளிப்படையாகக் குறிக்கப்படும்.
