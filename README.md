# தொல்காப்பியப் பூங்கா — பக்கவாரி மின்னாக்கம்

கலைஞர் மு. கருணாநிதி எழுதிய **தொல்காப்பியப் பூங்கா** நூலின் 537-பக்க ஸ்கேன் பிரதியைப் பக்கம்தோறும் வாசித்து, Markdown வடிவில் பாதுகாக்கும் களஞ்சியம்.

## நோக்கம்

- மூல ஸ்கேனின் பக்க வரிசையை மாற்றாமல் பாதுகாத்தல்
- அட்டை, பதிப்புத் தகவல், பதிப்புரை, உள்ளடக்கம் போன்ற முன்பக்கங்களை தனித்தனியாகப் பதிவு செய்தல்
- நூலில் உள்ள 100 “மலர்” தலைப்புகள், அதிகாரம், இயல், நூற்பா எண்கள் மற்றும் புத்தகப் பக்க எண்களை உள்ளடக்க அட்டவணைப்படி பாதுகாத்தல்
- ஒவ்வொரு ஸ்கேன் பக்கத்துக்கும் தனி Markdown கோப்பு உருவாக்குதல்
- படிக்க முடியாத அல்லது உறுதியாகத் தெரியாத எழுத்துகளை ஊகித்து நிரப்பாமல் வெளிப்படையாகக் குறித்தல்

## களஞ்சிய அமைப்பு

```text
metadata/                 நூல் மற்றும் மின்னாக்கத் தகவல்கள்
indexes/                  உள்ளடக்கம், மலர் அட்டவணை, பக்க வரைபடம்
pages/                    ஒவ்வொரு ஸ்கேன் பக்கத்திற்கும் தனி Markdown
chapters/                 அணிந்துரை, பூங்கா புகுமுன் மற்றும் 100 மலர்களின் அமைப்பு
```

## மின்னாக்க நிலைகள்

- `verified` — ஸ்கேனுடன் நேரடியாக ஒப்பிட்டு உறுதிப்படுத்தப்பட்டது
- `partial` — ஒரு பகுதி மட்டும் தெளிவாக வாசிக்கப்பட்டது
- `needs-review` — ஸ்கேன்-உதவிய முதல் பதிவு; இறுதி எழுத்துக்கு எழுத்து ஒப்பீடு தேவை
- `not-started` — இன்னும் வாசிக்கப்படவில்லை

## முதல் சுற்று நிறைவு

நூலின் **537 ஸ்கேன் பக்கங்களும்**, **100 மலர்களும்**, முன்பக்கங்களும் நிறைவுப் பக்கங்களும் பக்கவாரி Markdown பதிவாக அமைக்கப்பட்டுள்ளன.

## இறுதி மூல ஒப்பீட்டு முன்னேற்றம்

முழுமையாக `verified` செய்யப்பட்ட பகுதிகள்:

- **பேராசிரியர் க. அன்பழகன் அணிந்துரை — ஸ்கேன் 10–23**
- **மலர் (1) — எழுத்து — ஸ்கேன் 42–46**
- **மலர்கள் (2)–(100) — ஸ்கேன் 47–537**

- இறுதி ஒப்பீடு செய்யப்பட்ட `needs-review` உரைப் பக்கங்கள்: **422**
- மீதமுள்ள `needs-review` உரைப் பக்கங்கள்: **0**
- 100 மலர்களின் அனைத்து `needs-review` உரைப் பக்கங்களுக்கும் மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது.

## தமிழ்–ஆங்கில இருமொழி ஒப்பீடு

தமிழ் *தொல்காப்பியப் பூங்கா* மற்றும் அதன் ஆங்கில மொழிபெயர்ப்பு *The Flower-garden of Tolkāppiyam* ஆகிய இரு பதிப்புகளின் 100 மலர் / Blossom அமைப்பு, அதிகாரம், இயல், நூற்பா குறிப்புகள் ஒப்பிடப்பட்டுள்ளன. களஞ்சிய மின்னாக்கத்தில் ஒரு மலரோ அத்தியாயமோ விடுபட்டதற்கான ஆதாரம் இல்லை. பதிப்புகளுக்கிடையே காணப்படும் மூன்று நூற்பா-குறிப்பு வேறுபாடுகள் மற்றும் மலர் 24-ன் விளக்க இடைச்செருகல் பற்றிய விவரம் [`BILINGUAL_ALIGNMENT.md`](BILINGUAL_ALIGNMENT.md)-ல் பதிவு செய்யப்பட்டுள்ளது.

> குறிப்பு: இது தானியங்கி OCR வெளியீட்டை அப்படியே ஏற்ற களஞ்சியம் அல்ல. ஒவ்வொரு பக்கமும் ஸ்கேனை அடிப்படையாகக் கொண்டு அமைக்கப்படுகிறது; மூலத்தில் காணப்படும் சொல் வடிவங்கள் அமைதியாகச் சீர்திருத்தப்படாது.
