# மின்னாக்கக் கொள்கை

## அடிப்படை விதிகள்

1. ஒவ்வொரு PDF ஸ்கேன் பக்கமும் தனி Markdown கோப்பாகப் பதிவு செய்யப்படும்.
2. மூலத்தில் உள்ள தலைப்புகள், பத்திகள், அட்டவணைகள், மேற்கோள் குறிகள், எண்கள் மற்றும் வரிசை இயன்றவரை மாற்றமின்றிப் பாதுகாக்கப்படும்.
3. அச்சுப் பிழை எனத் தோன்றினாலும் மூல வாசிப்பு அமைதியாகத் திருத்தப்படாது.
4. தெளிவாகப் படிக்க முடியாத இடங்கள் ஊகித்து நிரப்பப்படாது.
5. கையெழுத்து, முத்திரை, புகைப்படம் போன்ற அச்சற்ற கூறுகள் தனி குறிப்பாகப் பதிவு செய்யப்படும்.

## சந்தேகக் குறியீடுகள்

- `[படிக்க முடியவில்லை]` — எழுத்து தெளிவாக இல்லை
- `[?]` — முன் உள்ள வாசிப்பு உறுதிப்படுத்தப்பட வேண்டும்
- `[மூலத்தில் அப்படியே]` — வழக்கத்திற்கு மாறான எழுத்து அல்லது வடிவம் மூலத்திலேயே உள்ளது

## கோப்பு முன்தலைப்பு

ஒவ்வொரு பக்கக் கோப்பிலும் குறைந்தபட்சம் பின்வரும் தகவல்கள் இடம்பெறும்:

```yaml
scan_page: 1
printed_page: null
section: front-matter
status: verified
```

## நிலை மதிப்புகள்

- `verified`
- `partial`
- `needs-review`
- `not-started`

## உள்ளடக்க அட்டவணை

ஸ்கேன் பக்கங்கள் 6–9-ல் உள்ள 100 மலர் அட்டவணை, தனிப்பக்கப் பதிவுகளுடன் சேர்த்து `indexes/contents.md` கோப்பிலும் ஒருங்கிணைக்கப்படும். இதுவே அத்தியாயக் கோப்புறைகளை உருவாக்குவதற்கான அதிகாரப்பூர்வ வரைபடமாகப் பயன்படுத்தப்படும்.
