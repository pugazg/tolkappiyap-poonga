- தொடக்கம்: ஸ்கேன் பக்கம் 369 / அச்சுப் பக்கம் 368
- முடிவு: ஸ்கேன் பக்கம் 372 / அச்சுப் பக்கம் 371

## பகுதியின் அமைப்பு

நாணம் என்பது ஆடவரைக் கண்டதும் தலைகுனிவது அல்ல; அறம், பொருள், இன்பம் ஆகியவற்றோடு இணைந்து மனித வாழ்வின் உயிர்ப்பண்பாகத் திகழ வேண்டியது என்பதை விளக்குகிறது.
