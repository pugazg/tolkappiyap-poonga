# மலர் (19) — நிலமும் பொழுதும்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: அகத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 6, 7, 8, 9, 10, 12
- தொடக்கம்: ஸ்கேன் பக்கம் 139 / அச்சுப் பக்கம் 138
- முடிவு: ஸ்கேன் பக்கம் 143 / அச்சுப் பக்கம் 142
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

முல்லை, குறிஞ்சி, மருதம், நெய்தல், பாலை ஆகிய திணைகளுக்குரிய பெரும்பொழுது–சிறுபொழுது வகைப்பாடுகளும் திணை மயக்கம் மற்றும் நில மயக்கமின்மையும் தொகுக்கப்படுகின்றன.
