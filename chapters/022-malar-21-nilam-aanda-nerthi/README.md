## பகுதியின் அமைப்பு

திணைநிலைப் பெயர் மற்றும் தொழில்பெயர், ஓதல்–தூது, போர், பொருள் காத்தல் மற்றும் நில ஆளுமை ஆகியவற்றுக்குரிய தலைமைத் தகுதிகளை எடுத்துரைத்து, “நால்வர்க்கும்” என்பதை வருணப் பிரிவாகத் திரிக்கும் வாசிப்பை மறுக்கிறது.
