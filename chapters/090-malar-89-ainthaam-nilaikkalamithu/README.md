# மலர் (89) — ஐந்தாம் நிலைக்களமிது

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: உவமையியல்
- தொடர்புடைய நூற்பாக்கள்: 5
- தொடக்கம்: ஸ்கேன் பக்கம் 473 / அச்சுப் பக்கம் 472
- முடிவு: ஸ்கேன் பக்கம் 476 / அச்சுப் பக்கம் 475
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

இழிவான அல்லது தாழ்ந்த பொருளை ஒப்புமையாகக் கொள்ளும் ஐந்தாவது உவமை நிலைக்களத்தை நகைச்சுவைக் கதையின் வழியாக விளக்குகிறது.
