# மலர் (6) — பிறப்பியல் பெருமை

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: பிறப்பியல்
- தொடர்புடைய நூற்பாக்கள்: 1
- தொடக்கம்: ஸ்கேன் பக்கம் 68 / அச்சுப் பக்கம் 67
- முடிவு: ஸ்கேன் பக்கம் 73 / அச்சுப் பக்கம் 72
- மொத்தம்: 6 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 5 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

பனம்பாரனார் மற்றும் புலவர்களின் உரையாடல் வழியாக எழுத்தொலிகளின் உடல் பிறப்பிடங்களும் தமிழ் உச்சரிப்பின் நுட்பமும் எடுத்துரைக்கப்படுகின்றன.
