# மலர் (44) — எரிந்தது ஈர விறகு

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: களவியல்
- தொடர்புடைய நூற்பாக்கள்: 11
- தொடக்கம்: ஸ்கேன் பக்கம் 279 / அச்சுப் பக்கம் 278
- முடிவு: ஸ்கேன் பக்கம் 285 / அச்சுப் பக்கம் 284
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

காதலரின் சந்திப்பு உடல் நெருக்கமாக மாறும் காட்சியின் வழியாக மெய்தொட்டுப் பயிறல் முதல் தீராத் தேற்றம் வரையிலான களவியல் குறிப்புகள் விளக்கப்படுகின்றன.

## பக்க எண் குறிப்பு

மூல உள்ளடக்க அட்டவணையின் தொடக்கப் பக்கம் மற்றும் தொடர்ச்சியான ஸ்கேனில் ஊகிக்கப்படும் அச்சுப் பக்கம் ஒரு பக்கம் மாறுபடுகிறது. இங்கு ஸ்கேன் வரிசையும் அடுத்தடுத்த பக்கங்களில் அச்சிடப்பட்டுள்ள எண்களும் முதன்மையாகப் பாதுகாக்கப்பட்டுள்ளன.
