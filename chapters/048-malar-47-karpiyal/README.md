## பகுதியின் அமைப்பு

“மேலோர் மூவர்”, “கீழோர்” ஆகிய சொற்களுக்கு வருணப் பாகுபாடு சார்ந்த உரைகளையும் மூவேந்தர்–குடிமக்கள் சார்ந்த மாற்று விளக்கத்தையும் வைத்து கரணம் எனும் மணமுறையை ஆராய்கிறது.
