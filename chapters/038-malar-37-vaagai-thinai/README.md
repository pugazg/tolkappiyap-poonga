# மலர் (37) — வாகைத் திணை

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 20
- தொடக்கம்: ஸ்கேன் பக்கம் 238 / அச்சுப் பக்கம் 237

- மொத்தம்: 9 ஸ்கேன் பக்கங்கள்

- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)

## பகுதியின் அமைப்பு

வாகை என்பது போர்வெற்றி மட்டுமல்லாது வாழ்வியல் கடமைகளில் பெறும் வெற்றியும் எனக் கூறி, சமூகத் தொழிற்பாகுபாடுகள், பார்ப்பன மரபு, வேள்வி–யாகம் மற்றும் வடமொழி ஆதிக்கம் குறித்த நூலாசிரியரின் விமர்சனம் விரிவடைகிறது.
