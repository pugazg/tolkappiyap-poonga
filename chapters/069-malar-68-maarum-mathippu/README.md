# மலர் (68) — மாறும் மதிப்பு

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 51
- தொடக்கம்: ஸ்கேன் பக்கம் 392 / அச்சுப் பக்கம் 391
- முடிவு: ஸ்கேன் பக்கம் 395 / அச்சுப் பக்கம் 394
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

சினம், பேதைமை, பொறாமை, வறுமை ஆகிய விரும்பத்தகாத பண்புகளைக் குறிக்கும் சொற்களும் இடத்துக்கேற்பச் சிறப்புப் பொருள் பெறுவதை எடுத்துக்காட்டுகளால் விளக்குகிறது.
