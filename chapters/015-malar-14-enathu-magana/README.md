## பகுதியின் அமைப்பு

மணவிழா அழைப்பிதழில் “எனது மகன்” என்பதற்குப் பதிலாக “எனக்கு மகன்” அமைய வேண்டிய வேற்றுமை உருபு விதி, அச்சக உரையாடலின் வழியாக விளக்கப்படுகிறது.
