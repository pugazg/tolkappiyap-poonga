## பகுதியின் அமைப்பு

கருத்தரிப்பு, குழந்தைப் பிறப்பு, குடும்ப மகிழ்ச்சி, தலைவனின் வேறுபெண் நாட்டம் மற்றும் ஊடல் தீர்வு ஆகிய இல்வாழ்வு நிலைகளை கற்பியல் நூற்பாவுடன் இணைக்கிறது.
