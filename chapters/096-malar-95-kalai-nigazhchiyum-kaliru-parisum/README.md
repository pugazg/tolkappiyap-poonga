# மலர் (95) — கலைநிகழ்ச்சியும் களிறு பரிசும்!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: மரபியல்
- தொடர்புடைய நூற்பாக்கள்: 35, 36, 47
- தொடக்கம்: ஸ்கேன் பக்கம் 498 / அச்சுப் பக்கம் 497
- முடிவு: ஸ்கேன் பக்கம் 501 / அச்சுப் பக்கம் 500
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

“கலை”, “முசு”, “களிறு”, “கேழல்” ஆகிய விலங்குப் பெயர்களின் பல்பொருள் மரபை அரண்மனை விகடகவிகளின் நகைச்சுவை நிகழ்ச்சியுடன் இணைக்கிறது.
