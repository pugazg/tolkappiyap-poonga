# மலர் (46) — இருபொருள் - ஒரு விளக்கம்!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: களவியல்
- தொடர்புடைய நூற்பாக்கள்: 44, 45
- தொடக்கம்: ஸ்கேன் பக்கம் 292 / அச்சுப் பக்கம் 291
- முடிவு: ஸ்கேன் பக்கம் 296 / அச்சுப் பக்கம் 295
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

கோவலன்–கண்ணகி மணவாழ்வை முன்னிறுத்தி, களவியலிலுள்ள “ஓரை” என்பதன் நேரம்/விழா என்ற இருபொருள் விளக்கங்களையும் நாள்கோள் மரபைப் பற்றிய உரையாசிரியர் வேறுபாடுகளையும் ஆராய்கிறது.
