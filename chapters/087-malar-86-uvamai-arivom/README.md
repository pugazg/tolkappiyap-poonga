# மலர் (86) — உவமை அறிவோம்!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: உவமையியல்
- தொடர்புடைய நூற்பாக்கள்: 1, 2
- தொடக்கம்: ஸ்கேன் பக்கம் 461 / அச்சுப் பக்கம் 460
- முடிவு: ஸ்கேன் பக்கம் 465 / அச்சுப் பக்கம் 464
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

வினை, பயன், மெய், உரு எனும் நான்கு வகை உவமைகளையும், புலன்களாலும் மனத்தாலும் அறியப்படும் ஒப்புமைகளையும், உவமைகள் கலந்து வருவதையும் விளக்குகிறது.
