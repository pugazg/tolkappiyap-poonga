# மலர் (53) — சுற்றுலா

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: 50
- தொடக்கம்: ஸ்கேன் பக்கம் 333 / அச்சுப் பக்கம் 332
- முடிவு: ஸ்கேன் பக்கம் 335 / அச்சுப் பக்கம் 334
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 2 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

குடும்பத்தினர் ஊரை விட்டு நீர்த்துறைகள் மற்றும் சோலைகளுக்குச் சுற்றுலா சென்று இயற்கை இன்பம் நுகர்வதைக் கற்பியல் வழக்காக எடுத்துரைக்கிறது.
