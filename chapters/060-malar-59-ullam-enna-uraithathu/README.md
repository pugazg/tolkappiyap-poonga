# மலர் (59) — உள்ளம் என்ன உரைத்தது?

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 9, 10
- தொடக்கம்: ஸ்கேன் பக்கம் 351 / அச்சுப் பக்கம் 350
- முடிவு: ஸ்கேன் பக்கம் 353 / அச்சுப் பக்கம் 352
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 2 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

தலைவனை காண்பதில்லை என உறுதிபூண்ட தலைவி, உடலும் உயிரும் வாடும் நிலையில் தன் நெஞ்சுடன் உரையாடி, அவனைச் சேரும் விருப்பத்தை உணர்கிறாள்.
