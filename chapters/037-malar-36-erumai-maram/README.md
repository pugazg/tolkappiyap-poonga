## பகுதியின் அமைப்பு

தும்பைப் போரின் கொடுமை, அம்பு–வேல்களுக்கு உடலைக் கேடயமாக்கும் வீரன், படை பின்னடைந்தபோது தனியொருவனாகத் தாங்கும் “எருமை மறம்”, வேந்தர் வீழ்ச்சிக்குப் பிந்தைய வீரச் செயல்கள் ஆகியவை எடுத்துரைக்கப்படுகின்றன.
