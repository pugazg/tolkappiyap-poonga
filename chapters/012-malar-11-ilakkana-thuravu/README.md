# மலர் (11) — இலக்கணத் துறவு

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: சொல்லதிகாரம்
- இயல்: கிளவியாக்கம்
- தொடர்புடைய நூற்பாக்கள்: 27
- தொடக்கம்: ஸ்கேன் பக்கம் 95 / அச்சுப் பக்கம் 94
- முடிவு: ஸ்கேன் பக்கம் 99 / அச்சுப் பக்கம் 98
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது
