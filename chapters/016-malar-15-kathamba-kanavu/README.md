# மலர் (15) — கதம்பக் கனவு!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: சொல்லதிகாரம்
- இயல்: கிளவியாக்கம்
- தொடர்புடைய நூற்பாக்கள்: 12
- தொடக்கம்: ஸ்கேன் பக்கம் 117 / அச்சுப் பக்கம் 116
- முடிவு: ஸ்கேன் பக்கம் 123 / அச்சுப் பக்கம் 122
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

கூவாகம் திருவிழாவைத் தொடர்ந்து அரவாணி இராதா காணும் கனவில், பேடி வடிவிலுள்ள அர்ச்சுனனும் கண்ணபிரானும் பாலைக் குறிக்கும் சொல்லாட்சி குறித்து உரையாடுகின்றனர்.
