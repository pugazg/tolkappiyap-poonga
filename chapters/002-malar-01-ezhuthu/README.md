# மலர் (1) — எழுத்து

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: நூல் மரபு
- தொடர்புடைய நூற்பாக்கள்: 1, 2
- தொடக்கம்: ஸ்கேன் பக்கம் 42 / அச்சுப் பக்கம் 41
- முடிவு: ஸ்கேன் பக்கம் 46 / அச்சுப் பக்கம் 45
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- நிலை: முழுப் பகுதியும் ஸ்கேனுடன் ஒப்பிட்டு பதிவுசெய்யப்பட்டது

## பகுதியின் அமைப்பு

தொல்காப்பியர் எழுத்ததிகாரத்தைத் தொடங்குவதற்கு முன் சிந்தனையில் ஆழ்வதாக ஒரு கற்பனைக் காட்சியுடன் மலர் தொடங்குகிறது. உயிர் மற்றும் மெய் எழுத்துகள் அணிவகுத்து நிற்க, குற்றியலிகரம், குற்றியலுகரம், ஆய்த எழுத்து ஆகியவை உரையாடல் வடிவில் அறிமுகப்படுத்தப்படுகின்றன. இறுதியில் நூல் மரபின் முதல் இரண்டு நூற்பாக்கள் மேற்கோளிடப்பட்டு, முப்பது முதலெழுத்துகளுக்கும் மூன்று சார்பெழுத்துகளுக்கும் உள்ள வேறுபாடு விளக்கப்படுகிறது.
