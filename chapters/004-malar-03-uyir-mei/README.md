# மலர் (3) — உயிர் மெய்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: நூல் மரபு
- தொடர்புடைய நூற்பாக்கள்: 18
- தொடக்கம்: ஸ்கேன் பக்கம் 52 / அச்சுப் பக்கம் 51
- முடிவு: ஸ்கேன் பக்கம் 55 / அச்சுப் பக்கம் 54
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 0
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

அண்ணா நினைவிடம், கவிதாஞ்சலி மற்றும் கருணாநிதி என்ற பெயரை முன்வைத்து மெய்–உயிர் சேர்ந்து உயிர்மெய் தோன்றுவது விளக்கப்படுகிறது.
