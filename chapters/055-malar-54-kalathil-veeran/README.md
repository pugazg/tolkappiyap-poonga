# மலர் (54) — களத்தில் வீரன்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: 45
- தொடக்கம்: ஸ்கேன் பக்கம் 336 / அச்சுப் பக்கம் 335
- முடிவு: ஸ்கேன் பக்கம் 338 / அச்சுப் பக்கம் 337
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 2 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)

## பகுதியின் அமைப்பு

போர்க்களத்தில் வெற்றியை முதன்மைப்படுத்தும் வீரன், வெற்றி பெற்ற பின்னரே தலைவியை நினைப்பான் எனும் கற்பியல் விதியை எடுத்துரைக்கிறது.
