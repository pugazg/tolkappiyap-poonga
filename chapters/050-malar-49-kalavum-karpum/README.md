# மலர் (49) — களவும் கற்பும்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: 5
- தொடக்கம்: ஸ்கேன் பக்கம் 309 / அச்சுப் பக்கம் 308
- முடிவு: ஸ்கேன் பக்கம் 315 / அச்சுப் பக்கம் 314
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

களவொழுக்கத்திலிருந்து கரணம் வழி கற்பு வாழ்க்கைக்குள் நுழைந்த தம்பதியரின் மலிவு, புலவி, ஊடல், உணர்வு மற்றும் பிரிவு நிலைகளை கற்பியல் நூற்பாவுடன் இணைக்கிறது.
