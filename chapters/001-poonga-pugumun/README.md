# பூங்கா புகுமுன்

- ஆசிரியர்: மு. கருணாநிதி
- தொடக்கம்: ஸ்கேன் பக்கம் 33 / அச்சுப் பக்கம் 32
- முடிவு: ஸ்கேன் பக்கம் 41 / அச்சுப் பக்கம் 40
- மொத்தம்: 9 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 8
- முழுப்பக்க ஓவியம்: ஸ்கேன் 34 / அச்சுப் பக்கம் 33
- தேதி: செப்டம்பர் 1, 2002
- இடம்: கோவா
- நிலை: முழுப் பகுதியும் ஸ்கேனுடன் ஒப்பிட்டு பதிவுசெய்யப்பட்டது

இந்தப் பகுதி சிறப்புப் பாயிர மேற்கோள், தொல்காப்பியத்தின் எழுத்து–சொல்–பொருள் அமைப்புக்கான பலாப்பழ உருவகம், இலக்குவனார் மற்றும் வ. சுப. மாணிக்கனார் மேற்கோள்கள், ஆசிரியரின் நன்றிக் குறிப்பு மற்றும் கையொப்பத்துடன் நிறைவடைகிறது.
