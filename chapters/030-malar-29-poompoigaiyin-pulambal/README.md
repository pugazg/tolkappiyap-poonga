# மலர் (29) — பூம்பொய்கையின் புலம்பல்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: அகத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 48
- தொடக்கம்: ஸ்கேன் பக்கம் 191 / அச்சுப் பக்கம் 190
- முடிவு: ஸ்கேன் பக்கம் 195 / அச்சுப் பக்கம் 194
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மருதக்கலியில் வண்டு, கருங்குவளை, யானை மதநீர், முல்லை மற்றும் பூம்பொய்கை ஆகிய இயற்கைக் காட்சிகளின் பின்னால் தலைவனின் பரத்தைமை குறித்த தலைவியின் புலம்பல் மறைபொருளாக அமைவது “உள்ளுறை உவமம்” என விளக்கப்படுகிறது.
