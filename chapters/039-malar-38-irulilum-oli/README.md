# மலர் (38) — இருளிலும் ஒளி

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 21
- தொடக்கம்: ஸ்கேன் பக்கம் 247 / அச்சுப் பக்கம் 246
- முடிவு: ஸ்கேன் பக்கம் 250 / அச்சுப் பக்கம் 249
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 0 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

பாசறைப் பயிற்சி, உழவர் வெற்றி, முன்தேர்–பின்தேர் குரவை, வீரத் தியாகம், பகைவரிடத்தும் அன்பு, சான்றோர் மாண்பு, கொடை, மன்னிப்பு மற்றும் துறவு ஆகிய வாகைத் திணைத் துறைகள் ஒளிமிகு பண்புகளாகச் சுருக்கப்படுகின்றன.
