# மலர் (67) — மெய்யன்பர் அறியாத மெய்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 35, 36, 37
- தொடக்கம்: ஸ்கேன் பக்கம் 384 / அச்சுப் பக்கம் 383
- முடிவு: ஸ்கேன் பக்கம் 391 / அச்சுப் பக்கம் 390
- மொத்தம்: 8 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 7 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

“இறைச்சி” என்ற இலக்கணச் சொல்லை மாமிச உணவாகத் தவறாகப் புரிந்து கொள்ளும் சிவபக்தரின் நகைச்சுவைக் கதையின் வழியாக, இறைச்சிப் பொருள் மற்றும் குறிப்புப்பொருள் விளக்கப்படுகின்றன.
