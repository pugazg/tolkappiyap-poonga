# மலர் (31) — பெருந்திணை

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: அகத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 51
- தொடக்கம்: ஸ்கேன் பக்கம் 203 / அச்சுப் பக்கம் 202
- முடிவு: ஸ்கேன் பக்கம் 206 / அச்சுப் பக்கம் 205
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மடலேறுதல், இளமை தீர்ந்த பின்னரான காம விருப்பம், அளவுகடந்த காம மிகுதி, வலிமையால் விருப்பத்தை நிறைவேற்ற முயல்வது ஆகிய நான்கு நிலைகளும் “பெருந்திணை” என விளக்கப்படுகின்றன.
