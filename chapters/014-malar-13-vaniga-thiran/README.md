# மலர் (13) — வணிகத் திறன்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: சொல்லதிகாரம்
- இயல்: கிளவியாக்கம்
- தொடர்புடைய நூற்பாக்கள்: 35
- தொடக்கம்: ஸ்கேன் பக்கம் 105 / அச்சுப் பக்கம் 104
- முடிவு: ஸ்கேன் பக்கம் 110 / அச்சுப் பக்கம் 109
- மொத்தம்: 6 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 5 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

புத்தகக் கடையில் வாடிக்கையாளர் கேட்ட நூல் இல்லாவிட்டாலும் வேறு நூலைச் சொல்லி விற்பனை செய்யும் வணிக முறையின் வழியாக, கேட்ட பொருள் இல்லையெனில் பிறிதொரு பொருளைக் கூறும் தொல்காப்பிய விதி விளக்கப்படுகிறது.
