## பகுதியின் அமைப்பு

பொருளதிகாரத்தின் வரலாற்றுப் பெருமையை முன்னிறுத்தி, முதற்பொருளாகிய நிலம் மற்றும் பொழுது பற்றிய அறிமுகமும் முல்லை, குறிஞ்சி, மருதம், நெய்தல் நிலங்களின் தெய்வக் குறிப்புகளும் வழங்கப்படுகின்றன.
