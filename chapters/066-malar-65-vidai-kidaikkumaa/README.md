- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்

## பகுதியின் அமைப்பு

காதலர் சந்திப்பைத் தொடர்ந்து தலைவி உடன்போக்கா அல்லது உடனடி மணவிழாவா எனத் தலைவனிடம் விடை கேட்க, அவன் பனையோலை மணவோலையை வெளிப்படுத்துகிறான்.

> இந்தப் பாதை பழைய குறியீட்டு இணைப்புடன் ஒத்திசைவைக் காக்கும் மாற்றுப்பாதையாகும்.
