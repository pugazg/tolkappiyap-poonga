# மலர் (8) — மானம்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: உயிர் மயங்கியல்
- தொடர்புடைய நூற்பாக்கள்: 69
- தொடக்கம்: ஸ்கேன் பக்கம் 79 / அச்சுப் பக்கம் 78
- முடிவு: ஸ்கேன் பக்கம் 85 / அச்சுப் பக்கம் 84
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- நிலை: பக்கவாரி முதல் பதிவு முடிந்தது; உரைப் பக்கங்கள் இறுதி எழுத்து-ஒப்பீட்டுக்காக `needs-review` எனக் குறிக்கப்பட்டுள்ளன

## பகுதியின் அமைப்பு

‘மானம்’ மற்றும் ‘சாரியை’ ஆகிய சொற்களின் பலபொருள் தன்மையைப் பயன்படுத்தி ஆடூஉ–மகடூஉ பெயர்களிடையே ‘இன்’ சாரியை வருவதைக் கதை வடிவில் விளக்குகிறது.
