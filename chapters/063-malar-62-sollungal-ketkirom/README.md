## பகுதியின் அமைப்பு

“இலக்கியம்” சொல்லின் தோற்றம் குறித்த 1949 கோவை முத்தமிழ் மாநாட்டு விவாதத்தை நினைவுகூர்ந்து, “உயர்ந்தோர் கிளவி” மற்றும் மொழிவழக்கு குறித்த உரையாசிரியர் வேறுபாடுகள் ஆராயப்படுகின்றன.
