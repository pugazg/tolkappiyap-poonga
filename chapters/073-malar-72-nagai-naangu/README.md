# மலர் (72) — நகை, நான்கு!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: மெய்ப்பாட்டியல்
- தொடர்புடைய நூற்பாக்கள்: 4
- தொடக்கம்: ஸ்கேன் பக்கம் 407 / அச்சுப் பக்கம் 406
- முடிவு: ஸ்கேன் பக்கம் 412 / அச்சுப் பக்கம் 411
- மொத்தம்: 6 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 0
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

எள்ளல், இளமை, பேதைமை, மடன் ஆகிய நான்கு காரணங்களால் நகை தோன்றும் விதத்தை நிகழ்ச்சிகள் மற்றும் கவிதைகளால் எடுத்துரைக்கிறது.
