# மலர் (74) — இளிவரல், நான்கு!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: மெய்ப்பாட்டியல்
- தொடர்புடைய நூற்பாக்கள்: 6
- தொடக்கம்: ஸ்கேன் பக்கம் 419 / அச்சுப் பக்கம் 418
- முடிவு: ஸ்கேன் பக்கம் 422 / அச்சுப் பக்கம் 421
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மூப்பு, பிணி, வருத்தம், மென்மை ஆகியவை இளிவரலுக்குக் காரணமாகும் விதத்தை குடும்ப மற்றும் சமூகச் சூழல்களால் விளக்குகிறது.
