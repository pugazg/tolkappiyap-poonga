## பகுதியின் அமைப்பு

தலைவன் தலைவியை அழைத்துச் செல்லும் நிலையில், தோழி தலைவனிடம் நியாயம் கேட்பது, தலைவியைத் தேற்றுவது, வாய்மை–பொய்மையை ஆராய்வது மற்றும் இருவரையும் இணைத்து அனுப்புவது போன்ற பொறுப்புகள் பட்டியலிடப்படுகின்றன.
