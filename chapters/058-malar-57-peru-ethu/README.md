# மலர் (57) — பேறு எது?

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: 51
- தொடக்கம்: ஸ்கேன் பக்கம் 344 / அச்சுப் பக்கம் 343
- முடிவு: ஸ்கேன் பக்கம் 346 / அச்சுப் பக்கம் 345
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 2 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

இல்லற வாழ்வின் இறுதிக்காலத்தில் மக்கள் மற்றும் அறம்புரியும் சுற்றத்துடன் அமைதியாகச் சிறந்ததைப் பயிற்றல் பெரும் பேறு என விளக்குகிறது.
