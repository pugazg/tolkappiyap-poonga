## பகுதியின் அமைப்பு

“பெண்மகன்” என்ற பழைய வழக்குச் சொல்லும் அது பெண்பால் வினை கொள்ளும் விதமும் அன்னம், மரகதம், தங்கம் ஆகியோரின் உரையாடலில் விளக்கப்படுகிறது.
