# மலர் (58) — ஒரு பாற் கூற்று

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 2
- தொடக்கம்: ஸ்கேன் பக்கம் 347 / அச்சுப் பக்கம் 346
- முடிவு: ஸ்கேன் பக்கம் 350 / அச்சுப் பக்கம் 349
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

காமநோயின் இன்ப–துன்ப நிலைகள், நெஞ்சொடு கிளத்தல், பறவையிடம் தூது கூறுதல், உவமை வழி இருவருக்கும் உரிய கூற்றை வெளிப்படுத்துதல் ஆகிய பொருளியல் கூறுகளை விளக்குகிறது.
