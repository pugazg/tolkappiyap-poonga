# மலர் (32) — மானமும் வீரமும் காத்த மறவர்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 2, 3
- தொடக்கம்: ஸ்கேன் பக்கம் 207 / அச்சுப் பக்கம் 206
- முடிவு: ஸ்கேன் பக்கம் 213 / அச்சுப் பக்கம் 212
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

வெட்சி–கரந்தைப் போர்களின் நோக்கம், ஆநிரை கவர்தலும் மீட்டலும், போர்த் தயாரிப்பின் பதினான்கு நிலைகள் மற்றும் ஒளவையார் பாடல் வழியிலான வீர–மானப் பதிவு தொகுக்கப்படுகிறது.
