# மலர் (30) — மருதநாயகி

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: அகத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 50
- தொடக்கம்: ஸ்கேன் பக்கம் 196 / அச்சுப் பக்கம் 195
- முடிவு: ஸ்கேன் பக்கம் 202 / அச்சுப் பக்கம் 201
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மருத நில இந்திர விழாவில் அரங்கேறும் சாகுந்தல நாடகத்தின் ஒப்பனை அறைக் காட்சியில், வயதான நடிகனின் ஒருதலைக் காதலை இளம் நடிகை மறுப்பதன் வழியாக “கைக்கிளை” விளக்கப்படுகிறது.
