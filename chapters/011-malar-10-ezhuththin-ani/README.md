# மலர் (10) — எழுத்தின் அணி!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: பிறப்பியல்
- தொடர்புடைய நூற்பாக்கள்: 19
- தொடக்கம்: ஸ்கேன் பக்கம் 91 / அச்சுப் பக்கம் 90
- முடிவு: ஸ்கேன் பக்கம் 94 / அச்சுப் பக்கம் 93
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

அரசியல் அணிகளை உருவகமாகக் கொண்டு குற்றியலிகரம், குற்றியலுகரம், ஆய்தம் ஆகிய சார்பெழுத்துகளின் பிறப்பியல் நிலை விளக்கப்படுகிறது.
