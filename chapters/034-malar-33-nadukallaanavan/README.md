# மலர் (33) — நடுகல்லானவன்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 5
- தொடக்கம்: ஸ்கேன் பக்கம் 214 / அச்சுப் பக்கம் 213
- முடிவு: ஸ்கேன் பக்கம் 218 / அச்சுப் பக்கம் 217
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

போரில் அணிகளை அடையாளப்படுத்தப் பூக்கள் சூடும் வழக்கம், கரந்தைப் போரின் வெற்றி, வெற்றிக்குப் பின் உயிரிழந்த அரசிளங்குமரனுக்குக் நடுகல் நாட்டும் மரபு ஆகியவை கதை வடிவில் விளக்கப்படுகின்றன.
