# மலர் (40) — தமிழ் வழி; தனி வழி

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: களவியல்
- தொடர்புடைய நூற்பாக்கள்: 1
- தொடக்கம்: ஸ்கேன் பக்கம் 258 / அச்சுப் பக்கம் 257
- முடிவு: ஸ்கேன் பக்கம் 263 / அச்சுப் பக்கம் 262
- மொத்தம்: 6 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 0 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மறையோர் மரபின் எட்டு மணமுறைகள் மற்றும் தமிழர் களவொழுக்க மரபு வேறுபடுத்தப்படுகின்றன; உள்ளப் புணர்ச்சி, பாங்கன்–பாங்கியர் துணை, அறம்–பொருள்–இன்பம் இணைந்த அன்பு ஆகியவை தமிழ்வழி என விளக்கப்படுகின்றன.
