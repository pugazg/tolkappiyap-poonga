# மலர் (91) — உருவகமா உவமையா?

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: உவமையியல்
- தொடர்புடைய நூற்பாக்கள்: 9
- தொடக்கம்: ஸ்கேன் பக்கம் 480 / அச்சுப் பக்கம் 479
- முடிவு: ஸ்கேன் பக்கம் 482 / அச்சுப் பக்கம் 481
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 2 (`needs-review`)
- முழுப்பக்க ஓவியங்கள் / புகைப்படங்கள்: 1 (`verified`)
- நிலை: பக்கவாரி முதல் பதிவு முடிந்தது; உரைப் பக்கங்கள் இறுதி எழுத்து-ஒப்பீட்டுக்காக `needs-review` எனக் குறிக்கப்பட்டுள்ளன

உவமைக்கும் உருவகத்திற்கும் உள்ள வேறுபாட்டைத் தாமரை–முகம் எடுத்துக்காட்டாலும் இலக்கண நூற்பாவாலும் விளக்குகிறது.
