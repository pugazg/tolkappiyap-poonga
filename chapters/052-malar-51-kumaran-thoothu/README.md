# மலர் (51) — குமரன் தூது

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: 5
- தொடக்கம்: ஸ்கேன் பக்கம் 322 / அச்சுப் பக்கம் 321
- முடிவு: ஸ்கேன் பக்கம் 326 / அச்சுப் பக்கம் 325
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

குழந்தையின்மையால் ஊடல் கொண்ட வேலன்–வஞ்சி தம்பதியரிடம் குமரன் தூதாகச் சென்று, பிரிவை நீக்கி இணக்க வாழ்வை ஏற்கச் செய்கிறான்.
