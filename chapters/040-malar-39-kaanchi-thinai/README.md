# மலர் (39) — காஞ்சித் திணை

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 24
- தொடக்கம்: ஸ்கேன் பக்கம் 251 / அச்சுப் பக்கம் 250
- முடிவு: ஸ்கேன் பக்கம் 257 / அச்சுப் பக்கம் 256
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

வாழ்க்கையின் நிலையாமை, போர்க்கள மரணம், பேய்ப்பக்கம், வஞ்சினம், கணவன்–மனைவி பிரிவு, வீரமகளிரின் துயரம் உள்ளிட்ட காஞ்சித் திணைத் துறைகள் நூற்பாவாகவும் நீண்ட கவிதையாகவும் வழங்கப்படுகின்றன.
