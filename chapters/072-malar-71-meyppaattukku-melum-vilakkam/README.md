# மலர் (71) — மெய்ப்பாட்டுக்கு மேலும் விளக்கம்!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: மெய்ப்பாட்டியல்
- தொடர்புடைய நூற்பாக்கள்: 1
- தொடக்கம்: ஸ்கேன் பக்கம் 403 / அச்சுப் பக்கம் 402
- முடிவு: ஸ்கேன் பக்கம் 406 / அச்சுப் பக்கம் 405
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

மெய்ப்பாடு என்பது உள்ளுணர்வு புறக்குறிகளால் வெளிப்படுவது என்பதைச் சுவைப்படுபொருள், சுவை, குறிப்பு, விறல் ஆகிய கூறுகளுடன் விளக்குகிறது.
