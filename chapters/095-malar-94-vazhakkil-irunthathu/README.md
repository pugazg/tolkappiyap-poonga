- இயல்: மரபியல்
- தொடர்புடைய நூற்பாக்கள்: 48

## பகுதியின் அமைப்பு

ஆடினத்தின் ஆணுக்குப் பழங்காலத்தில் வழங்கிய “அப்பர்” என்ற சொல்லின் வழக்கொழிவை, நீதிதேவன் முன்னிலையிலான நகைச்சுவைக் கற்பனை வழியாக விளக்குகிறது.
