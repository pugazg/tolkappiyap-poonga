# மலர் (24) — இடையில் ஓர் எளிய விளக்கம்?

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: —
- இயல்: —
- தொடர்புடைய நூற்பாக்கள்: —
- தொடக்கம்: ஸ்கேன் பக்கம் 163 / அச்சுப் பக்கம் 162
- முடிவு: ஸ்கேன் பக்கம் 167 / அச்சுப் பக்கம் 166
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

“திணை”, உயர்திணை–அஃறிணை, அகத்திணை, கைக்கிளை, பெருந்திணை, ஐந்திணை மற்றும் புறத்திணை ஆகிய அடிப்படைச் சொற்களுக்கு வாசகர்கள் தொடர்ந்து வரும் பகுதிகளை எளிதில் அணுகும் வகையில் இடைநிலை விளக்கம் வழங்கப்படுகிறது.
