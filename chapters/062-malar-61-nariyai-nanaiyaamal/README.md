# மலர் (61) — நரியை நனையாமல்...!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 16
- தொடக்கம்: ஸ்கேன் பக்கம் 359 / அச்சுப் பக்கம் 358
- முடிவு: ஸ்கேன் பக்கம் 363 / அச்சுப் பக்கம் 362
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

போர்ப்பாசறையில் உள்ள தலைவனுக்குத் தலைவி அனுப்பிய பனையோலை மடலைத் தோழி கொண்டு வருகிறாள். வழி, பொழுது, காவல், இடையூறு ஆகியவற்றால் சந்திப்பு தாமதமாவது பொருளியல் நூற்பாவுடன் இணைக்கப்படுகிறது.
