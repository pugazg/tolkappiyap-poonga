# மலர் (22) — மறப்புக்குப் பரிசு!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: அகத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 34
- தொடக்கம்: ஸ்கேன் பக்கம் 151 / அச்சுப் பக்கம் 150
- முடிவு: ஸ்கேன் பக்கம் 157 / அச்சுப் பக்கம் 156
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

வகுப்பறைப் பரிசுப் போட்டியில் கடற்பயணத்துக்கு மனைவியை அழைத்துச் செல்லும் காட்சியை எழுதிய முகிலனின் கட்டுரைக்கு, “முந்நீர் வழக்கம் மகடூஉவோடு இல்லை” என்ற மரபை நினைவூட்டிய முல்லைக்கொடியின் மறுப்பே பரிசைப் பெறுகிறது.
