# மலர் (64) — இன்பம் எங்கே?

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: பொருளியல்
- தொடர்புடைய நூற்பாக்கள்: 29
- தொடக்கம்: ஸ்கேன் பக்கம் 373 / அச்சுப் பக்கம் 372
- முடிவு: ஸ்கேன் பக்கம் 376 / அச்சுப் பக்கம் 375
- மொத்தம்: 4 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 3 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

இன்பம் எல்லா உயிர்களுக்கும் பொதுவான உணர்வு என்றாலும், அன்பினால் மனம் பொருந்திய ஆண்–பெண் இணைவில் அது சிறப்பியல்பை அடைகிறது என்ற பொருளியல் கருத்தை விளக்குகிறது.
