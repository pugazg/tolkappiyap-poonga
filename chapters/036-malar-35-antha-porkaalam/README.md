# மலர் (35) — அந்தப் பொற்காலம்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: புறத்திணை இயல்
- தொடர்புடைய நூற்பாக்கள்: 13
- தொடக்கம்: ஸ்கேன் பக்கம் 224 / அச்சுப் பக்கம் 223
- முடிவு: ஸ்கேன் பக்கம் 230 / அச்சுப் பக்கம் 229
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

கோட்டை முற்றுகை, குடை–வாள் நாள்கோள், ஏணி மற்றும் மதிற்போர், வெற்றிவாளுக்கான நீராட்டு, வீழ்ந்த வேந்தன் பெயரால் முடிபுனைதல் ஆகிய உழிஞைத் திணைச் செய்திகள் விவரிக்கப்படுகின்றன.
