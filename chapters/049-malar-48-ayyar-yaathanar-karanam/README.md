# மலர் (48) — அய்யர் யாத்தனர் கரணம்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: களவியல் / கற்பியல்
- தொடர்புடைய நூற்பாக்கள்: களவியல் 48, 49 / கற்பியல் 4
- தொடக்கம்: ஸ்கேன் பக்கம் 302 / அச்சுப் பக்கம் 301
- முடிவு: ஸ்கேன் பக்கம் 308 / அச்சுப் பக்கம் 307
- மொத்தம்: 7 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 6 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

களவொழுக்கத்தில் பொய்யும் வழுவும் தோன்றிய பின் பெரியோர்கள் “கரணம்” எனும் மணச் சடங்கை வகுத்தனர் என்ற கருத்தையும் “அய்யர்” சொல்லின் பொருளையும் ஊரவை நிகழ்ச்சியால் விளக்குகிறது.
