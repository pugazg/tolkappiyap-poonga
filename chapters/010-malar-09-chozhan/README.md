# மலர் (9) — சோழன்

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: எழுத்ததிகாரம்
- இயல்: தொகை மரபு
- தொடர்புடைய நூற்பாக்கள்: 13
- தொடக்கம்: ஸ்கேன் பக்கம் 86 / அச்சுப் பக்கம் 85
- முடிவு: ஸ்கேன் பக்கம் 90 / அச்சுப் பக்கம் 89
- மொத்தம்: 5 ஸ்கேன் பக்கங்கள்
- உரைப் பக்கங்கள்: 4 (`verified`)
- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
- நிலை: மூல ஸ்கேனுடன் இறுதி எழுத்து-ஒப்பீடு முடிந்தது

## பகுதியின் அமைப்பு

சோழன் என்ற பெயர் உயர்திணை மனிதரையும் அஃறிணைப் பேருந்தையும் குறிக்கலாம் என்பதன் வழியாக இருதிணைக்கும் உரிய பொதுப்பெயர் விளக்கப்படுகிறது.
