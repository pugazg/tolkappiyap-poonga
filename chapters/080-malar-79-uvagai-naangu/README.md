# மலர் (79) — உவகை நான்கு!

- ஆசிரியர்: மு. கருணாநிதி
- அதிகாரம்: பொருளதிகாரம்
- இயல்: மெய்ப்பாட்டியல்
- தொடர்புடைய நூற்பாக்கள்: 11
- தொடக்கம்: ஸ்கேன் பக்கம் 437 / அச்சுப் பக்கம் 436
- முடிவு: ஸ்கேன் பக்கம் 439 / அச்சுப் பக்கம் 438
- மொத்தம்: 3 ஸ்கேன் பக்கங்கள்

- முழுப்பக்க ஓவியங்கள்: 1 (`verified`)
