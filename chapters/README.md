# அத்தியாய அமைப்பு

இந்த நூல் முன்னுரைப் பகுதிக்குப் பின் **100 “மலர்”** தலைப்புகளாக அமைந்துள்ளது. அதிகாரம், இயல், நூற்பா மற்றும் தொடக்கப் பக்க விவரங்களுக்கு [ஒருங்கிணைந்த உள்ளடக்க அட்டவணை](../indexes/contents.md) பார்க்கவும்.

## முன்பகுதி

- ஸ்கேன் 1–5: அட்டை மற்றும் பதிப்புத் தகவல்கள்
- ஸ்கேன் 6–9: “பூங்காவின் உள்ளே...” — 100 மலர் உள்ளடக்க அட்டவணை
- ஸ்கேன் 10 / அச்சுப் பக்கம் 9: **அணிந்துரை** தொடக்கம்
- அணிந்துரையின் முடிவு: அச்சுப் பக்கம் 40-க்கு முன் என உள்ளடக்க அட்டவணையிலிருந்து தெரிகிறது; பக்கவாரி வாசிப்பில் சரியான எல்லை உறுதிப்படுத்தப்படும்.

## மலர் கோப்புறை பெயரிடல்

ஒவ்வொரு மலரும் வாசிக்கப்பட்டபின் பின்வரும் வடிவில் தனிக் கோப்புறையாக உருவாக்கப்படும்:

```text
chapters/001-ezhuthu/
chapters/002-uyirum-meyyum/
...
chapters/100-nooravathu-malar/
```

ஒவ்வொரு கோப்புறையிலும்:

```text
README.md                 மலர் விவரம் மற்றும் மூல நூற்பா இணைப்பு
pages/                    அந்த மலருக்குச் சேர்ந்த பக்கவாரி Markdown கோப்புகள்
```
