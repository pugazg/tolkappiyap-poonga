# மலர் (81) — இரண்டாம் நிலை மெய்ப்பாடுகள் · தொடர்ச்சி 2

## உரை

ஆடை நெகிழ்ந்ததோ வென்று
அவிழ்த்து உடுத்தப் பார்த்தாள்! இப்படி
இரண்டாம் நிலை மெய்ப்பாடுகள் நான்காம்; அவை
இன்ப லீலை தொடக்கத்தின் பாங்காம்!

★

“கூழை விரித்தல், காதொன்று களைதல்,
ஊழணி தைவரல், உடை பெயர்த்துடுத்தலொடு
கெழீஇய நான்கே இரண்டென மொழிப”

(பொருளதிகாரம் - மெய்ப்பாட்டியல் -
நூற்பா : 14)

கூழை = கூந்தல்

காதொன்று களைதல் = தோடு
விழுந்துவிட்டதாகத் தேடுதல்

ஊழணி தைவரல் = அணிகளைத் தடவிப்
பார்த்தல்.
