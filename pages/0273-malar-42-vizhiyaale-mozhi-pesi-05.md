# மலர் (42) — விழியாலே மொழி பேசி · தொடர்ச்சி 5

## உரை

பாங்கன் வாழ்த்தினான்
பரிவுடன் தமிழ்ப் பண்புடன்!

★

1. “நாட்டம் இரண்டும் அறிவு உடம்படுத்தற்குக்
கூட்டி உரைக்கும் குறிப்புரை ஆகும்”

2. “குறிப்பே குறித்தது கொள்ளுமாயின்
ஆங்கவை நிகழும் என்மனார் புலவர்”

3. “பெருமையும் உரனும் ஆடூஉ மேன”

4. “அச்சமும் நாணும் மடனும் முந்துறுத்த
நிச்சமும் பெண்பாற்கு உரிய என்ப”

(பொருளதிகாரம் - களவியல் -
நூற்பா : 5, 6, 7, 8)

நாட்டம் = விருப்பம்
உரன் = வலிமை
ஆடூஉ = ஆடவர்
மடன் = அறியாமை
நிச்சம் = நித்தம்
